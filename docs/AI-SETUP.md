# 配置说明：两个 Key，两阶段出卷

App 现在分两步：**千问 VL 只负责「看图转文字」**，**DeepSeek 负责「写解析 + 翻译」**。所以需要两个 Key：

| 阶段 | 模型 | 需要哪个 Key |
|---|---|---|
| ① 扫描（只出原文/题干/选项，不答题不解析不翻译） | 通义千问视觉模型（首选 `qwen3-vl-plus`，自动降级） | **千问 API Key** |
|   解析（老师确认答案 → 生成译文与解析，并核对答案） | `deepseek-chat` | **DeepSeek API Key** |
| 编辑器里点「译」兜底翻译 | 千问 `qwen-plus` | 千问 Key |

两个 Key 都只存本机 SQLite，不上传、不随试卷包导出。

---

## 一、千问 API Key（扫描必填）

1. 登录 [阿里云百炼控制台](https://bailian.console.aliyun.com/)（注册 + 实名 + 开通百炼）。
2. 右上角 **API-KEY** → 创建 → 复制（`sk-…`）。
3. App：设置 → **千问 API Key** → 粘贴 → 保存。

内置：`https://dashscope.aliyuncs.com/compatible-mode/v1`（国内站）与 `dashscope-intl`（国际站）自动切换；视觉模型按 `qwen3-vl-plus → qwen-vl-plus-latest → qwen-vl-max-latest → 旧名 → qwen2.5-vl-72b` 顺序自动探测，**模型改名不会 404**。

## 二、DeepSeek API Key（解析必填）

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/) → 登录 → **API Keys** → 创建 → 复制。
2. App：设置 → **DeepSeek API Key** → 粘贴 → 保存。

内置：`https://api.deepseek.com/v1`，模型 `deepseek-chat`。余额不足会报 402。

---

## 三、两阶段工作流

```
① 扫描（千问 VL）
   选图 → 后台识别 → 得到「扫描卷」：原文 / 题干 / 选项 / 题号 / 重点词
   （不答题、不写解析、不翻译；图表题只转写文字）
        ↓  这时就可以先保存为「扫描卷」
  确认答案（老师）
   编辑器里逐题选/填答案：可以自己拟定，也可以照原卷答案填
        ↓
③ 生成解析（DeepSeek）
   点「生成解析并保存解析卷」→ 逐篇生成：中文译文 + 每题解析
   AI 会先独立作答；若与你的答案不一致，App 会弹出「AI 答案与你的答案不符」清单，
   逐条「保留我的」或「采用 AI 答案」
        ↓
④ 保存 → 「解析卷」（答案 + 译文 + 讲评）→ 阅读页可逐题显示答案与解析
```

**为什么这样拆**：视觉模型贵在「看大图」，文本模型贵在「写长文」。只让 VL 转文字、让 DeepSeek 写解析，整卷成本明显下降，解析质量也更好控制。

---

## 四、成本控制

| 做法 | 省在哪 |
|---|---|
| 按篇切图再扫 | 单图越小，视觉 token 越少 |
| 先存扫描卷，讲解后补 | 不必一次生成全部解析 |
| 解析按篇生成 | 失败只重试那一篇 |
| 翻译用「译」按需点 | 不必整卷重译 |

---

## 五、安全与隐私

| 事项 | 说明 |
|---|---|
| Key 存放 | 本机 SQLite；不导出、不上传 |
| 卸载 App | 两个 Key 一并删除 |
| 断网 | 已保存的卷、答题、收藏本全部可用；只有扫描/解析/翻译需要联网 |

---

## 六、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 扫描 `HTTP 401` | 千问 Key 错/失效/欠费 | 重建 Key |
| 扫描 `404 model_not_found` | 模型名不可用 | App 已自动换模型；全失败则检查是否开通视觉模型、Key 站点是否匹配 |
| 扫描只出一半 | 图片糊/太长 | 按篇切图、提高清晰度 |
| 点「生成解析」提示没填 Key | DeepSeek Key 为空 | 设置里填 DeepSeek Key |
| 解析 `HTTP 402` | DeepSeek 余额不足 | 充值 |
| 解析 `HTTP 401` | DeepSeek Key 错 | 重建 Key |
| 弹出「AI 答案与你的答案不符」 | 模型独立作答与你的答案不同 | 逐条确认：保留你的（解析按 AI 答案写，可能需微调）或采用 AI 的 |
| 某篇解析失败其他篇成功 | 单篇太长/超时 | 重试该篇；或先保存扫描卷之后补 |
| 扫描卷看不到译文/解析 | 正常，扫描卷只有原文题目 | 生成解析后才有 |
| 保存后作答被清空 | 同 id 覆盖 | 改试卷 id，或先删旧卷 |
